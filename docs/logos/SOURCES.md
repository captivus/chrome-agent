# Logo sources

The logos in this directory appear in the README's "Used by engineers at" section. The list reflects the stated affiliations of GitHub users who use chrome-agent. It does not imply that any of these organizations endorses the project. All names and logos are trademarks of their respective owners.

Every file was changed from its source in the same way:

- It was recolored to a single gray (`#6e7781`). The original artwork is now a mask, so white details inside a logo are transparent rather than white.
- Its viewBox was cropped to the artwork, and its intrinsic size was set to 100px tall, so that the README's `height` attribute controls the size it renders at.
